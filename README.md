# CI/CD Final Project

## Project Name
CI/CD Pipeline for Application Deployment using GitHub Actions, Tekton and OpenShift

## Project Description
This project demonstrates the implementation of a Continuous Integration and Continuous Delivery (CI/CD) pipeline using GitHub Actions, Tekton and Red Hat OpenShift.

The pipeline automates code validation, unit testing, application building and deployment.

## Technologies Used
- Git and GitHub
- GitHub Actions
- Python
- Flake8
- Nose
- Tekton
- Red Hat OpenShift
- Kubernetes

## Project Objectives
- Implement Continuous Integration using GitHub Actions.
- Automate code linting and unit testing.
- Create Tekton tasks for pipeline execution.
- Configure OpenShift Pipelines.
- Deploy the application using a CI/CD workflow.
